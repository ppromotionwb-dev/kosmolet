# Космолёт

Браузер для работы: быстрый и лёгкий, с Claude «внутри» и с расширенными инструментами разработчика. Внутри — Chromium 156 (тот же движок, что у Google Chrome), поэтому сайты открываются как в Chrome, а кабинеты маркетплейсов работают как обычно.

Чем отличается от обычного Chrome:

- **Claude видит браузер.** Claude Code может читать открытые вкладки, нажимать кнопки, заполнять поля и смотреть запросы сайта — по вашему разрешению. Терминал с Claude открывается прямо в боковой панели.
- **Инструменты под рукой.** DevTools, перехват запросов API, cookies, эмуляция телефона, свои скрипты и «Рентген» страницы — в одной панели справа (F12).
- **Тёмная тема для любого сайта**, свои темы оформления браузера.
- **Контейнеры:** разные кабинеты одного сайта одновременно в соседних вкладках.
- **Блокировщик рекламы** и расширения из Chrome Web Store.

## Как запустить

**Ярлык на рабочем столе.** Создаётся один раз командой (PowerShell, из папки проекта):

```
powershell -ExecutionPolicy Bypass -File tools\make-shortcut.ps1
```

На рабочем столе появится «Космолёт» со значком. Дальше запускайте его как обычную программу. Окно Космолёта можно закрепить на панели задач — закреплённый значок будет запускать именно Космолёт.

**Без ярлыка.** Дважды щёлкните `Запустить Космолёт.bat` в папке проекта.

Если папки `node_modules` нет (например, проект скопирован без неё), один раз выполните в папке проекта `npm install`.

Второй запуск не открывает второе окно: адрес передаётся в уже открытое.

## Что умеет

### Вкладки и адресная строка
- Привычные вкладки как в Chrome: закрепление, звук, перетаскивание, «открыть заново закрытую».
- Адресная строка ищет по истории, закладкам и открытым вкладкам.
- **Бэнги** — короткие префиксы поиска: `wb кроссовки` (Wildberries), `oz чайник` (Ozon), `ym`, `av` (Авито), `g`, `я`, `ddg`, `gh` (GitHub), `npm`, `mdn`, `so` (Stack Overflow), `yt`, `tr` (переводчик). Число после `wb` или `oz` открывает карточку товара: `wb 123456789`. Свои бэнги добавляются в Настройки → Поиск.
- **Командная палитра** — `Ctrl+K`: любая команда браузера, вкладка, закладка или бэнг по нескольким буквам.
- Неактивные вкладки выгружаются из памяти через 30 минут (настраивается) и загружаются снова, когда к ним вернётесь. Вкладки восстанавливаются после перезапуска.

### Контейнеры
Каждый контейнер — отдельный набор cookies и входов. Удобно держать несколько кабинетов WB или Ozon одновременно. Контейнеры создаются в Настройки → Контейнеры (там же кнопка «+ Новая вкладка» у каждого), ещё новая вкладка в контейнере открывается через меню «⋯» → «Новая вкладка в контейнере», а ссылка — правым кликом → «Открыть в контейнере». Цвет контейнера виден на вкладке, а в адресной строке — чип с его названием (клик по чипу — меню контейнера).

**Изолированная вкладка** — вкладка в своём собственном контейнере, без новых окон и профилей: `Ctrl+Shift+N`, Shift+клик по «+», правый клик по ссылке → «Открыть в изолированной вкладке». Можно включить режим «Каждая новая вкладка — изолированная» (Настройки → Контейнеры) — тогда так открываются `Ctrl+T` и «+». Ссылки и всплывающие окна со страницы остаются в её контейнере. Такой контейнер временный (в чипе кружок-кольцо): когда закрыта его последняя вкладка, он удаляется вместе со входом. Чтобы сохранить вход — меню чипа → «Оставить контейнер» или кнопка «Оставить» в настройках. Claude через MCP тоже умеет: `tab_open` с `isolated`, `container_create`, `containers_list` — например, по контейнеру на каждый кабинет маркетплейса.

### Блокировщик рекламы и расширения
- Блокировщик включён сразу. Щит в адресной строке показывает состояние: с галкой — на странице что-то заблокировано (число — в подсказке и в окне щита), перечёркнутый — блокировщик выключен. Клик по щиту открывает окно: переключатель в шапке включает или выключает блокировку на этом сайте, кнопка внизу — «Выключить везде». Кабинеты продавцов WB, Ozon и Яндекс Маркета по умолчанию в исключениях.
- Расширения Chrome ставятся из Chrome Web Store (команда «Открыть Chrome Web Store») и управляются на странице «Расширения».

### Оформление
- Темы браузера: cosmos (по умолчанию), graphite, светлая, terminal и своя — Настройки → Оформление.
- **Тёмная тема для любого сайта**: значок луны в адресной строке или `Alt+Shift+D`. Два движка: **«Точный»** (Dark Reader — аккуратнее, но на тяжёлых сайтах замедляет загрузку) и **«Быстрый»** (один CSS-фильтр). Режим: «Выключена / Выбранные сайты / Все сайты». На Wildberries тема включена сразу, движком «Быстрый». Яркость, контраст, движок и свой CSS для сайта — в панели «Тема сайта» и в Настройки → Темы сайтов.

### Правая панель инструментов (F12)
Открывается кнопкой с панелью справа вверху или `F12`. Вкладки панели:

| Инструмент | Что делает |
|---|---|
| DevTools | Обычные инструменты разработчика Chrome |
| Сеть и API | Запросы сайта: ответы JSON деревом, «копировать как fetch / curl / PowerShell», повтор запроса, сохранение HAR |
| Хранилище | Cookies и localStorage сайта: просмотр, правка, удаление |
| Устройство | Эмуляция телефона или планшета, медленной сети, тёмной схемы, печати |
| Claude | Терминал с Claude Code и журнал его действий в браузере |
| Тема сайта | Тёмная тема и свой CSS для текущего сайта |
| Сниппеты | Свои скрипты для страниц и готовая библиотека |
| Рентген | SEO, технологии, скорость и безопасность страницы |
| Сайт | Что браузер узнал о сайте: его API, какие кнопки их вызывают, заметки |

### Сниппеты
Небольшие скрипты, которые выполняются на открытой странице. Есть готовая библиотека (только для чтения, её можно «Копировать в мои» и поменять):

- Все ссылки страницы — таблицей, с копированием в CSV/TSV;
- Таблица в буфер (TSV) — для вставки в Excel или Google Таблицы;
- Разблокировать копирование и ПКМ;
- Показать скрытые поля форм;
- Картинки без alt — подсветить;
- Все картинки (URL);
- Мета-теги и JSON-LD;
- Выключить анимации;
- Режим редактирования страницы — правка любого текста мышкой;
- **WB: артикулы на странице** — все nmId с поиска или каталога, с количеством;
- **Ozon: SKU на странице**;
- localStorage в JSON;
- Cookies страницы.

Свой сниппет: «Новый», пишете код, `Ctrl+Enter` — выполнить, `Ctrl+S` — сохранить. Результат показывается деревом, таблицей или текстом, ошибка — с номером строки. Работают `await` и `return`.

**Автозапуск:** включите переключатель и укажите сайты — например `wildberries.ru`, `*.ozon.ru` или `ozon.ru/product/*`. Сниппет будет выполняться сам при загрузке подходящих страниц. Когда автосниппеты сработали, в адресной строке появляется значок молнии, а в панели видно, какие именно выполнились и с каким результатом.

Выполнить любой сниппет можно и из палитры: `Ctrl+K` → «Выполнить сниппет…».

Режимы выполнения: **Изолированный** (по умолчанию) — сниппет видит страницу, но не её переменные, и сайт не может ему помешать; **Страница** — доступны переменные сайта (например, `window.jQuery`).

### Рентген страницы
Панель «Рентген» сама проверяет открытую страницу:

- **SEO:** title и description (с длиной), canonical, robots, язык, hreflang, H1 и структура H2–H3, Open Graph и Twitter, разметка JSON-LD, картинки без alt, ссылки, viewport, favicon;
- **Технологии:** React, Next.js, Nuxt, Vue, Angular, Svelte, Astro, Vite, jQuery, Tilda, 1С-Битрикс, WordPress, Shopify, Webflow, Google Tag Manager и GA4 (с ID), Яндекс Метрика (номер счётчика), пиксели Meta, VK, Top@Mail.ru, TikTok;
- **Скорость:** TTFB, FCP, LCP, CLS, DOMContentLoaded, загрузка, число и вес ресурсов по типам, самые тяжёлые файлы;
- **Сервер и безопасность:** сервер и CDN, протокол, сжатие, заголовки CSP, HSTS, X-Frame-Options, X-Content-Type-Options, Referrer-Policy.

У каждого пункта цветная точка: зелёная — хорошо, жёлтая — есть замечание, красная — проблема, серая — для сведения. Кнопки сверху: обновить, скопировать отчёт в Markdown, **отправить отчёт в Claude**. Если замеры скорости искажены тёмной темой («Точный» движок) или блокировщиком, Рентген пишет об этом первой заметкой.

### Claude
- **Терминал Claude** в панели: Claude Code уже подключён к браузеру.
- **«Отправить в Claude»** (`Ctrl+Shift+Y` или правый клик по странице): текст страницы, выделение и последние запросы API сохраняются в файл, путь вставляется в терминал Claude.
- **«Показать Claude элемент»** (`Ctrl+Shift+E`): щёлкните по элементу страницы — Claude получит его селектор и HTML.
- Когда Claude работает с вкладкой, она коротко подсвечивается, а все его действия видны в журнале (панель Claude → «Журнал»).

### Знания о сайтах
Космолёт сам запоминает, как устроен каждый сайт, на котором вы работаете, и хранит это между запусками.
- **Каталог API.** Пока вы (или Claude) пользуетесь сайтом, браузер записывает, к каким адресам API обращается страница, с какими параметрами, какие поля приходят в ответе и после какой кнопки это происходит («Найти», «По цене», «В корзину»). Всё сгруппировано по сайту: seller.wildberries.ru и www.wildberries.ru — это один сайт wildberries.ru.
- **Заметки.** Claude записывает туда свои находки о сайте (какой запрос работает, где что лежит), чтобы в следующий раз не искать заново. Вы тоже можете добавлять, править и удалять заметки.
- **Инструмент «Сайт»** в правой панели показывает всё это для сайта текущей вкладки: список запросов, карточку запроса с параметрами и структурой ответа, кнопку «Копировать как fetch», заметки и кнопку «Забыть сайт».
- **Claude** сначала смотрит каталог и заметки сайта и, где можно, получает данные прямым запросом, а не кликами по страницам — так быстрее и надёжнее. Свои заметки он может вести даже в режиме «Только чтение»: это его память, браузер и сайт они не меняют.
- **Приватность.** Сохраняются только адреса, имена полей и их типы (число, строка…), но не сами данные: ни ответов сайта, ни паролей, ни значений заголовков. Токены и ключи в адресах маскируются. Всё лежит только на этом компьютере.
- Выключить сбор, добавить сайты-исключения или очистить собранное — Настройки → Инструменты разработчика → «Знания о сайтах».

Сочетания работают в любой раскладке: `Ctrl+T` — это та же клавиша, что `Ctrl+Е`.

Исключения:
- **Пока курсор в терминале Claude**, сочетания `Ctrl` или `Alt` + буква (`Ctrl+T`, `Ctrl+W`, `Ctrl+L`, `Ctrl+R`, `Ctrl+F`, `Ctrl+K`…) уходят в терминал — у Claude Code и оболочки на них свои действия. Браузеру остаются F-клавиши, сочетания с `Ctrl+Shift`, `Ctrl+Tab`, `Ctrl+PgUp/PgDn` и `Ctrl+1…9`.
- **Внутри DevTools** работают их собственные `Ctrl+Shift+P` (меню команд DevTools) и `Ctrl+L` (очистить консоль).
- `Ctrl+K` открывает палитру Космолёта и на сайтах, поэтому собственный `Ctrl+K` сайтов (GitHub, Slack) не срабатывает.

## Как подключить Claude Code

Нужен установленный Claude Code (команда `claude` в терминале).

1. Нажмите кнопку **Claude** справа от адресной строки (значок с точкой-статусом; пока Claude Code ни разу не подключался, точка серая).
2. В открывшемся окне выберите режим доступа (**Выкл / Чтение / Полный**, по умолчанию «Полный») и нажмите **«Подключить к Claude Code»**. Космолёт сам выполнит `claude mcp add --scope user …` и добавит сервер `kosmolet` для всех ваших проектов.
3. Перезапустите Claude Code. В нём появятся инструменты `kosmolet` (26 штук): список вкладок, снимок страницы, клики, ввод текста, скриншоты, запросы сети и другие.

То же самое есть в Настройки → Claude. Если кнопка не сработала, там же есть готовая команда (кнопка «Команда») — её можно скопировать и выполнить в терминале самому. Если `claude` не находится в PATH, в Настройки → Claude можно указать полный путь к `claude.exe` или `claude.cmd`; аргументы и спецсимволы в этом поле не принимаются.

Терминал Claude внутри Космолёта (панель → Claude) подключать не нужно — он запускается уже с доступом к браузеру.

| Что | Где |
|---|---|
| Профиль браузера: настройки, сессия вкладок, история, закладки, сниппеты, расширения, cookies | `%APPDATA%\Kosmolet` |
| Знания о сайтах (каталог API и заметки) | `%APPDATA%\Kosmolet\site-intel` — по файлу на сайт |

Точные пути и кнопки «Открыть папку» — в Настройки → О Космолёте.

## Безопасность

- **Доступ Claude к браузеру — только с этого компьютера.** Сервер MCP слушает лишь адрес `127.0.0.1` и отвечает только на запросы с секретным токеном. Запросы из веб-страниц (с заголовком Origin) отклоняются — сайт не может управлять браузером через Claude.
- **Режимы доступа** (Настройки → Claude или поповер Claude): **Выключен** — сервер не работает; **Только чтение** — Claude видит вкладки, страницы, запросы и консоль, но ничего не нажимает; **Полный** — может также переходить по адресам, нажимать, вводить текст и выполнять код на странице.
- Токен можно перевыпустить в Настройки → Claude; после этого Claude Code нужно подключить заново.
- Все действия Claude записываются в журнал (панель Claude → «Журнал»), а вкладка, с которой он работает, подсвечивается.
- Сниппеты выполняются только по вашей команде или автозапуском на тех сайтах, которые вы указали. На служебных страницах Космолёта (`kosmo://…`) сниппеты не выполняются.
- Служебные страницы Космолёта недоступны сайтам: сайт не может открыть настройки или прочитать их содержимое.

## Для разработчика

- Устройство проекта и договорённости — в `ARCHITECTURE.md`, фактическое API ядра — в `docs/core-reports.md`.
- Запуск в режиме разработки со своим профилем: `powershell -File tools\start-dev.ps1 -Profile <имя> -DevPort <порт> -McpPort <порт> -CdpPort <порт>` (окно открывается за краем экрана; ключ `-OnScreen` — на экране), управление — `node tools/dev.mjs --port <порт> eval|shot|logs|quit`, проверка ядра — `node tools/smoke.mjs <devPort> <cdpPort>`, вызовы MCP — `node tools/mcp-call.mjs --profile <имя> list | call <инструмент> '<json>'`. Тестовые профили лежат в `.profiles\<имя>`.
- Иконка: исходники `assets/logo.svg` и `assets/logo-small.svg` (для 16–24 px). Пересобрать `assets/icon.ico` и `assets/icon.png`: `node_modules\electron\dist\electron.exe tools\make-icon.js` (с ключом `--preview` — увеличенные копии в `tools\dev-out\f-tools`).
- Ярлык: `tools\make-shortcut.ps1` (ключ `-OutDir` — другая папка).
